hermit-works の使い方を案内します。

関心のある領域（省略時は全体）: $ARGUMENTS

## 手順
1. `${CLAUDE_PLUGIN_ROOT}/README.md` を読み、「## 使い方」節のコマンド一覧表と「## スキル（作業手順書）」節のスキル一覧表を取得する。参照するのはプラグイン自身のこの README のみであり、利用者リポジトリ側のファイル（CLAUDE.md・`.hw/` 配下等）は読まない。
2. `$ARGUMENTS` が指定されている場合は、コマンド名・スキル名・用途の説明文のいずれかにその語を含む行に絞り込む。空の場合は両表の全行をそのまま対象とする（フォールバック）。
3. 絞り込んだ結果が0件の場合は「一致するコマンド・スキルなし」と伝えたうえで、両表の全行を表示するフォールバックに切り替える。
4. 「コマンド」「スキル」の2区分に分け、それぞれ表形式（またはそれに準ずる箇条書き）で日本語で表示する。
5. 末尾に案内を添える:
   - 誰が対応するか（エージェント一覧）を知りたい場合は `/hw:show-org` を案内する
   - 具体的な案件を依頼したい場合は `/hw:request <内容>` を案内する
