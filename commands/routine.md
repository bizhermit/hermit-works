hermit-works の定期実行をセットアップします。

要望（例: 「毎朝9時にレポート」）: $ARGUMENTS

## 手順
1. 要望から「実行するコマンド」と「頻度」を決める（判断を伴う。実行主体: この /hw:routine を実行しているエージェント自身が要望を解釈して決定する）。省略時は以下を提案する:
   - 毎日: `/hw:standup`（朝のスタンドアップ）
   - 毎週: `/hw:report`（週次の健全性レポート）
2. 実行環境に応じてセットアップする（判断を伴わない機械的作業。実行主体: いずれも呼び出し元が直接実行する）:
   - **スケジュール機能（schedule スキル / routines）が使える場合**: それを使って定期実行を登録する。プロンプトには対象コマンド（例: `/hw:report`）を指定する。
   - **使えない場合**: OS のスケジューラで headless 実行する方法を案内する。例（Windows タスクスケジューラ）:
     ```
     claude -p "/hw:report" --plugin-dir <このプラグインのパス>
     ```
     を実行するタスクを登録する手順を、実際のパスを埋めて提示する（テンプレートへのパス埋め込みのみで判断は伴わない）。
3. 登録内容（何を・いつ・どうやって）を `.hw/routines.md` に記録し、日本語で報告する（判断を伴わない機械的作業。実行主体: 呼び出し元が直接実行する）。

既存の定期実行を確認・変更したい場合は `.hw/routines.md` とスケジューラの登録状況を突き合わせて案内してください（実行主体: 呼び出し元が直接実行する）。
