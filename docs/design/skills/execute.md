# hw:execute

`hw:request`が作成した指示書を受け、実行計画を立て、計画のタスクごとに実行者に実施させ、評価者のレビューを経て成果物を仕上げる。手順の定めは[SKILL.md](../../../plugin/skills/execute/SKILL.md)にあり、本書はその処理フローを図で示す。

## 手順の処理フロー

図の読み方：

- 平行四辺形は依頼元との対話（問いと答え、承認）である。答えは`plan.md`の裁定の節に記す
- 二重枠は担当（サブエージェント）の起動である。実行者は`hw:worker`、評価者は`hw:reviewer`で、起動のたびに新しい人物である
- いずれの問いでも、答えまたは承認が得られなければ、問いを示したまま停止する
- 統括が行ったこと（問いと答え、承認、担当の起動、報告の受領、判定、状態の変更）は、その都度`plan.md`の経過の節に記す

### 全体の流れ

```mermaid
flowchart TD
    S([開始]) --> A1["指示書を読み、案件ディレクトリを作り、instruction.mdに写す"]
    A1 --> A2{"目的と完了条件があるか"}
    A2 -- ない --> X1(["停止：hw:requestで補うよう示す"])
    A2 -- ある --> B1[/"未確定事項を一件ずつ問う"/]
    B1 --> C1["plan.mdを書く（タスク、完了条件と確かめ方、触ってよい範囲、依存）"]
    C1 --> C2{"指示書の完了条件がすべて確かめられるか"}
    C2 -- 確かめられない条件がある --> C3[/"依頼元に示し、言い直しを問う"/]
    C3 --> C1
    C2 -- すべて確かめられる --> D1[/"plan.mdを示し、承認を問う"/]
    D1 --> D2{"承認か"}
    D2 -- 修正あり --> D3["修正を反映"]
    D3 --> D1
    D2 -- 承認 --> E1["タスクを依存の順に実行する（タスクの実行ループ）"]
    E1 --> F1[["評価者を起動（全体レビュー）"]]
    F1 --> F2{"判定"}
    F2 -- 差し戻し --> F3{"指摘が指すタスクがあるか"}
    F3 -- ある --> F4["そのタスクを差し戻す"]
    F4 --> E1
    F3 -- ない --> F5["タスクを追加する"]
    F5 --> D1
    F2 -- 承認 --> G1["指示書が求める後処理（コミット等）を行う"]
    G1 --> G2["plan.mdの結果を書き、依頼元に報告する"]
    G2 --> T([終了])
```

### タスクの実行ループ

全体の流れの「タスクを依存の順に実行する」で、タスクごとに次を繰り返す。互いに依存せず、触ってよい範囲が重ならないタスクは同時に進めてよい。

```mermaid
flowchart TD
    S([タスク開始]) --> W1[["実行者を起動（report-n）"]]
    W1 --> W2{"報告の結論"}
    W2 -- 判断待ち --> W3[/"判断を求める事項を一件ずつ問う"/]
    W3 --> W1
    W2 -- 中断 --> W4[/"報告を依頼元に示し、判断を問う"/]
    W4 --> U(["依頼元の判断に従う"])
    W2 -- 完了 --> R1[["評価者を起動（review-n）"]]
    R1 --> R2{"判定"}
    R2 -- 承認 --> R3["タスクを完了にする"]
    R3 --> T([次のタスクへ])
    R2 -- 差し戻し --> R4{"同じタスクの差し戻しが3回に達したか"}
    R4 -- 達した --> R5[/"指摘と経過を依頼元に示し、判断を問う"/]
    R5 --> U
    R4 -- 未満 --> W5["レビューを渡す"]
    W5 --> W1
```
