# Hermit Works 設計書

## リポジトリ構成

```text
/                          # 保守側（非配布）
├── .claude-plugin/
│   └── marketplace.json   # マーケットプレイス定義
├── CLAUDE.md              # 本リポジトリ保守用の指示
├── LICENCE                # ライセンス全文の正本
├── docs/
│   └── design/            # 設計書（本ディレクトリ）
│       ├── agents/        # エージェント設計書
│       └── skills/        # スキル設計書
└── plugin/                # 配布側（インストール時にコピーされる範囲）
    ├── .claude-plugin/
    │   └── plugin.json    # プラグインマニフェスト
    ├── LICENCE            # 配布用の写し
    ├── agents/            # エージェント
    ├── skills/            # スキル
    └── assets/            # 共通資材
```

## スキルとエージェントの境界

同じエージェントが別のスキルを使用しても変わらない記述はエージェントに、同じスキルを別のエージェントが使用しても変わらない記述はスキルに、どちらを替えても変わらない記述はどちらにもかかず上位の規範とする。

### スキルに書くべきもの

- 入り口と出口（I/O）：このスキルを実施するために必要な情報（input）と、そこから導き出される結果（output）を書く
- 手順（Flow）：進む道（rail）と止まる条件（traffic light）
