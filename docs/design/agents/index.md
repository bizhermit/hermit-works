# エージェント設計書

## エージェントの基本様式

```
---
name: <名前>
description: <説明>
---

# hw:<名前>

<所属グループと役職>

## 担当分野

- **<物事>**
    - 対象：<担うのはここまで>
    - 対象外：<ここからは担わない>

## 作業方針

- **<流儀の名前>**：<内容>
```

### 例外

`hw:bizhermit`は所属グループおよび役職を持たないため、基本様式の例外とする

## 個別のエージェント設計書

設計意図を個別に残す必要があるエージェントについては、個別のエージェント設計書（`docs/design/agents/<エージェント名>.md`）を作成しそこに記載する。
