# 共通の観点

すべてのレビューに適用する。段階ごとの観点はこの観点の内にある。

- 検証済み、推論、不明が区別され、検証済みには現物（パス、実行したコマンド、結果）が添えられ、現物がその事実を裏付けている。
- 行動から根本の目的までの連なりが切れておらず、依頼に無い目的や作業が加えられていない。
- 一つのものが一つのことだけを担い、目的に遡れない備え、汎用化、仲介、選択肢が含まれていない。
- 選択を含む産物では、目的を満たす案が並べられ、同じ物差しで比べられ、推奨に根拠がある。
- 既決を問い直しておらず、裁定記録にある裁定が反映されている。
- 統括が補った箇所が仮定として明示されている。
- `CLAUDE.md`の出力の表記に従っている。
