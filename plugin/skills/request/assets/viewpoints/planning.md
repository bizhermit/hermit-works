# 段階4 実行計画の観点

- すべての計画が完了すれば対応方針が実現され、漏れも重複もない。
- 各計画の完了条件が検証できる形で書かれている。
- 依存関係と実行順が整合し、同じ実行順の計画の対象が重なっていない。
- 各計画が一人の担当が一つのセッションで終えられる大きさである。
- 各計画ファイルが、担当が着手するのに足りる情報を持ち、根本の目的までの連なりが切れていない。
- 対応方針に無い作業が計画に加えられていない。
- 方針後のレビュー観点が、対応方針の分野に照らして漏れていない。
- 終点が計画なら、工数見積が計画ごとに根拠を持ち、合計が計画の工数と一致し、前提が明示されている。
