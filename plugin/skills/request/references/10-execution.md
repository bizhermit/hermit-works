# 手順10 分担実行

- タスクごとに生成作業（コード案・原稿・差分の作成）をサブエージェントへ委任する（エージェント組織の実装前は汎用サブエージェントで代替し、実装後は専門家へ差し替える。委任の共通事項はSKILL.mdの「実行体制」節に従う）。
- 委任時に渡すもの: 計画の`index.md`のパス・担当タスクID・計画に書けなかった動的な差分情報（直前タスクの結果を受けた軌道修正・差し戻し指摘など）。成果物案は各自の作業ディレクトリ`<サブエージェントID>/`（計画ディレクトリ配下）へ保存させる。
- 対象資材への適用（書き出し）は統括が行う。適用前に成果物案を確認し、矛盾・漏れ・スコープ外の変更・同一ファイルの重複更新が無いかを見る。
- 依存の無いタスクは並列で、依存のあるタスクは順に実行する。
- タスクの状態は統括が計画の`index.md`で更新する。
