# 手順2 背景とゴール

## 割り出しとヒアリング

- 依頼内容（案件の`index.md`の「依頼原文」節に記録済み）から背景（Why）・ゴール・スコープ外を割り出す。不明点は利用者に問う。
- 問いは後戻りコストの大きい論点から順に出す。
- この段階の問いは目安3〜7問で打ち切り、残りは推奨を添えて後段（対応方針・計画）へ回す。
- 事実確認・慣習的な軽い確認は一括提示してよい。複数案から利用者が決める裁定は1件ずつ提示する。

## 進め方の確認

- AskUserQuestionで進め方を4択（AI提案・カスタム・二人三脚・おまかせ）で確認する。各択の意味と以降の確認粒度はSKILL.mdの「進め方による確認粒度」節に従い、選択肢の説明にはその要約を用いる（本ファイルに択の定義は写さない）。
- 選択を案件の`index.md`の「進め方」行へ記録する。選択は案件単位であり、恒久文書へは記録しない。

## 記入

- 確定した背景・ゴール・スコープ外を案件の`index.md`へ追記する（各2行以内。スコープ外が無ければ「なし」と書く）。
