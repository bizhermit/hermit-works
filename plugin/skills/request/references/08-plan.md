# 手順8 実行計画作成

- 方針で確定した工程列を、案件の`index.md`の「計画」節へ実行順付き・状態「未着手」で先登録する（ディレクトリ名は計画の作成時に記入する）。依存なく並列に回せる計画群（並列群）には同じ実行順を与える（実行順の意味はSKILL.mdの手順8に従う）。1案件に複数の計画を持ってよく、計画名には工程名を用いる。
- 各計画の中身（タスクの細分化）は前工程の完了後に作成する。依存なく並列に回せる計画群は同時に作成してよい。
- 計画の作成は、計画ディレクトリ`.hw/plans/<YYYYMMDD>_<案件名>_<計画名>/`を作り、直下の`index.md`をひな型`${CLAUDE_PLUGIN_ROOT}/assets/plan.md`から作成する。「依頼原文」節へは、案件（背景・ゴール・`approach.md`）から当該計画へスコープを限定した依頼を記す。
- 立案はPlanエージェントを軸にする（委任の共通事項はSKILL.mdの「実行体制」節に従う）。
- タスクは正誤を判定できる単位まで細分化し、依存を明記する。依存の無いタスクは並列実行できる形にする。入力・成果物はパスで示す。
- 作成した計画は、案件の「計画」節の当該行へディレクトリ名を記入し、全体状態を更新する。
