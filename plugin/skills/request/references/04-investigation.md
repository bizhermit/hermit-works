# 手順4 現状調査

- 背景・ゴールから調査すべき論点を分解する。読み取り専用の調査であり、独立した論点はサブエージェントへ並列に委任する（委任の共通事項はSKILL.mdの「実行体制」節に従う）。
- 委任プロンプトには調査対象と報告してほしい形式を明示する。Planエージェントの調査結果は返答で受け取り、作業ファイルを持つサブエージェントには案件ディレクトリ配下の`<サブエージェントID>/`を割り当てる。
- 利用者作成の資材を調査の前提に使う場合は、SKILL.mdの「利用者作成資材の初出適用」節に従う。
- 調査結果を統括が`current-condition-report.md`（案件ディレクトリ直下）へまとめる。必須項目:
  - 調査した範囲と、調査しなかった範囲。
  - 事実（出典のパス・実行コマンドを添える）・推論・不明の区別。
