# 手順13 完了報告

## 裁定の棚卸しと転記

- 案件・計画の`index.md`の裁定記録を棚卸しし、案件完了後も効力を持つ裁定（規約・基準・方針）は、それを所管する文書の改訂として反映し、転記先を裁定記録の行へ追記する。
- 所管する文書が無い裁定は、載せ先の新設か出力しないかの裁定を利用者に仰ぐ。
- 利用者作成資材の適用可否の記録先は`.hw/conventions.md`の「適用判断」節である（SKILL.mdの「利用者作成資材の初出適用」節に従い記録済みであることを確認する）。

## 後始末

- 案件の`index.md`の段階表と案件全体の状態を「完了」にする。
- 子案件の場合は、親の`index.md`の「子案件」節の当該行の状態を更新し、残る兄弟子案件の見直し要否の提案を報告に含める（SKILL.mdの「子案件」節に従う）。
- サブエージェントの作業ディレクトリ`<サブエージェントID>/`は削除しない（SKILL.mdの「記録と状態」節に従う）。

## 報告

- 必須項目: 実施内容・成果物の場所・残課題・確認事項（あれば）・引き継ぎ事項（あれば）。本文は簡潔にし、詳細は成果物ファイルへの参照で示す。
- 「検証済み」と報告してよいのは、実行コマンドと実際の出力抜粋を添えられる場合のみとする。
- 親案件は、分割裁定と各子のゴール確定を成果物として完了し、子案件一覧を添えて報告する。
- 非対話実行の場合は、仮採用した裁定の一覧と追認の依頼、実行せず提案止まりにした操作を必ず含める。
