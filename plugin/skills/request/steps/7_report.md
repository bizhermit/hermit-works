# 段階7 完了報告

案件の結果を利用者に報告し、利用者の検収に委ねる。検収は依頼元のものであり、統括の報告は検収の代わりにならない。

## 手順

1. 案件の`index.md`と計画一覧を読み、記録が現状と一致していることを確かめる。
2. 次を報告する。
    - 目的と、それが果たされたことをどう確かめたか
    - 成果物の一覧。パスで示す
    - 自走レベルと、裁定の一覧。利用者の裁定、既決の適用、自律裁定を区別する
    - 残論点・保留とリスク
    - 省いたこと、やり残したこと、検証できなかったことと、その理由
    - コミットやプッシュを行ったならその内容、行っていないならその旨
3. 案件の状態を完了にする。利用者の検収で差し戻されたら、案件と段階4以降の状態を進行中に戻し、戻った理由を経過に書き、指摘を対処する計画を段階4の定めに従って追加して、段階5から進め直す。

## 報告の書き方

`CLAUDE.md`の出力の表記に従う。結論を先に書き、検証済み、推論、不明を区別し、都合の悪い事実を省かない。
