# 段階6 全体検収

すべての計画の成果物を合わせて、案件の目的が果たされたかを検証する。計画ごとの検収は計画の完了条件を見るが、本段階は目的を見る。

## 産物

案件の`index.md`の経過と残論点・保留。

## 手順

1. 評価者を起動し、案件の`index.md`、計画一覧、各計画の`index.md`のパスと、下の基準を渡す。評価者は計画ごとの検収を担った者とも実行者とも別の人物であれ。
2. 差し戻しなら、指摘を対処する計画を段階4の定めに従って計画一覧に追加し、段階5で実行して、再度本段階を行う。差し戻しの上限は品質ゲートと同じである。
3. 合格したら、判定と差し戻し回数、残論点・保留を記録する。

## 評価基準

- 目的に書かれた完了の条件が、現物で確かめられている。
- 計画の成果物を合わせたときに、矛盾、重複、抜けが無い。
- リポジトリ全体のテストや検証手段があるなら、評価者自身が実行して結果を見る。
- スコープ外に踏み込んだ変更が無い。
- 案件と各計画の残論点・保留が漏れなく集められている。
- 裁定記録にある裁定が成果物に反映されている。
