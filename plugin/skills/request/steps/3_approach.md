# 段階3 対応方針の裁定

目的を満たす案を並べて比べ、利用者の裁定を受けて対応方針を決める。何を作るか、どう組むかは利用者の裁定である。

## 産物

案件の`index.md`の対応方針の項目。採用した案と、比べた案および採用しなかった理由を書く。

## 手順

1. 目的を満たす案を複数出す。案ごとにゴール、単純さ、費用を同じ物差しで書く。物差しは目的、単純、費用の順である。
2. 案間の利害得失を、現状調査の事実に基づいて書く。推奨と根拠を書く。
3. 方針が不可逆か、誤ったときの手戻りが大きいなら、三役審議で案を練る。審議の結論は判断材料であり、裁定ではない。
4. 品質ゲートを通す。
5. 論点ごとに1件ずつ、判断材料を揃えて利用者に裁定を問う。利用者が推奨と逆を選び矛盾があれば一度だけ指摘し、維持されたら従う。裁定を裁定記録に追記する。
6. 採用した案を対応方針に書く。

## 評価基準

- 各案が目的を満たすかが明示され、満たさない案が選択肢に混ざっていない。
- 案が同じ物差しで比べられている。
- 利害得失が現状調査の検証済みの事実に基づいており、推論に基づく箇所は推論と明示されている。
- 推奨に根拠がある。
- 判断材料（問題と影響範囲、原因、複数案と各案のゴール、案間の利害得失、推奨と根拠）が揃っている。
- 目的に遡れない備え、汎用化、仲介、選択肢が案に含まれていない。
